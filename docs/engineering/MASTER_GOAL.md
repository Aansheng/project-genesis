# Project Genesis — Master Goal

## Durable product goal

Project Genesis turns natural-language game intent into a coherent, playable
and evolvable game:

Natural language
→ AI understands game intent
→ structured Game Design
→ Semantic World
→ Gameplay Specification
→ trusted Runtime execution
→ Renderer
→ mechanically complete playable 2D game
→ continuous natural-language evolution without resetting the world

The durable product goal is generic. It is not a commitment to a particular
copyrighted character, asset set, genre-specific Runtime, or provider.

## Example user intent

Examples are intent samples, not implementation contracts:

- 帮我生成一个马里奥式平台游戏
- 增加 Boss
- 让敌人更快
- 改成夜晚

The system should preserve stable world identity and apply later requests as
targeted, validated changes to the current world when the relevant capability
is supported. Unsupported or deferred behavior must remain explicit and must
not be presented as executed.

## Engineering implication

Every supervised work item should move the end-to-end playable pipeline forward
or make an existing product boundary truthful and verifiable. Engineering
control documents coordinate that work; they are not a second product runtime,
task database, or source of product truth.
