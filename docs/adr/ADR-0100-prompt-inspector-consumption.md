# ADR-0100: Prompt Inspector Consumption

**Status:** Accepted  
**Date:** Sprint 5  
**Work Order:** WO-S5-053  
**Architecture Version:** v0.87

---

## Context

The Prompt Inspector Foundation (WO-S5-052, ADR-0099) introduced `PromptInspector`, `PromptInspectorSection`, `PromptInspectorBuilder`, and `DefaultPromptInspectorBuilder` — but they were **not consumed** by `DefaultPromptBuilder`. The domain model existed, yet no production code produced an inspector.

### Problem

1. **No inspector produced** — the inspector domain model existed but was never generated
2. **No metadata field** — `metadata.promptAssembly.inspector` did not exist
3. **Foundation not consumable** — the builder was orphaned

---

## Decision

### BuilderOptions

Add an optional field:

```typescript
promptInspectorBuilder?: PromptInspectorBuilder
```

- Backward compatible — all existing fields unchanged
- Optional — omitting it produces no inspector

### DefaultPromptBuilder

Add a private field wired from `BuilderOptions`:

```typescript
private readonly promptInspectorBuilder?: PromptInspectorBuilder
```

Legacy constructor path wires it as `undefined`.

### New Phase — 0.959

Inserted between Phase 0.958 (PromptAssemblySnapshotBuilder) and Phase 0.96 (PromptAssemblyStrategy):

```text
PromptAssemblySnapshot (from Phase 0.958)
        ↓
PromptInspectorBuilder.build(snapshot)
        ↓
PromptInspector
        ↓
metadata.promptAssembly.inspector
```

Executed only when:
- `promptAssemblySnapshot` exists (from Phase 0.958)
- `promptInspectorBuilder` exists

### Metadata

Stored only when the inspector builder exists:

```typescript
metadata.promptAssembly.inspector  // PromptInspector
```

### Coexistence

The inspector is **additive** — it coexists with all existing fields:

- `strategy`
- `strategyRendered`
- `strategySelection`
- `strategyModule`
- `strategyModuleRendered`
- `plan`
- `optimizedPlan`
- `planDiff`
- `planRendered`
- `snapshot`

Nothing is removed or modified.

### NOT Modified

- `PromptRenderer` — unchanged
- `PromptCompression` — unchanged
- `Planner` — unchanged
- `Runtime` — unchanged
- `AgentLoop` — unchanged
- Prompt output — unchanged (metadata only, no prompt injection)

---

## Consequences

### Positive

1. **Inspector produced** — the domain model is now generated by production code
2. **Additive** — all existing metadata fields preserved
3. **Backward compatible** — optional field, no breaking changes
4. **No prompt changes** — metadata only
5. **Snapshot-dependent** — inspector requires snapshot to exist

### Negative

None.

### Neutral

1. Inspector is generated only when both snapshot builder and inspector builder are configured
2. Inspector reflects only data available in the snapshot at Phase 0.958
