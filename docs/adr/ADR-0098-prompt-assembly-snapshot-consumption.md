# ADR-0098: Prompt Assembly Snapshot Consumption

**Status:** Accepted  
**Date:** Sprint 5  
**Work Order:** WO-S5-051  
**Architecture Version:** v0.86

---

## Context

The Prompt Assembly Snapshot Foundation (WO-S5-050, ADR-0097) introduced `PromptAssemblySnapshot`, `PromptAssemblySnapshotBuilder`, and `DefaultPromptAssemblySnapshotBuilder` — but they were **not consumed** by `DefaultPromptBuilder`. The unified snapshot structure existed, yet no production code produced it.

### Problem

1. **No snapshot produced** — the snapshot structure existed but was never generated
2. **No unified diagnostics** — consumers still must read individual `metadata.promptAssembly` fields
3. **No snapshot in metadata** — `metadata.promptAssembly.snapshot` did not exist
4. **Foundation not consumable** — the builder was orphaned (interfaces without consumption)

---

## Decision

### BuilderOptions

Add an optional field to `BuilderOptions`:

```typescript
promptAssemblySnapshotBuilder?: PromptAssemblySnapshotBuilder
```

- Backward compatible — all existing fields unchanged
- Optional — omitting it produces no snapshot

### DefaultPromptBuilder

Add a private field wired from `BuilderOptions`:

```typescript
private readonly promptAssemblySnapshotBuilder?: PromptAssemblySnapshotBuilder
```

Legacy constructor path wires it as `undefined`.

### New Phase — 0.958

Inserted between Phase 0.957 (PromptAssemblyPlanRenderer) and Phase 0.96 (PromptAssemblyStrategy):

```text
promptAssembly metadata
        ↓
PromptAssemblySnapshotBuilder
        ↓
PromptAssemblySnapshot
        ↓
metadata.promptAssembly.snapshot
```

Phase 0.958 collects the individual promptAssembly fields computed by earlier phases (strategy, strategySelection, strategyRendered, strategyModule, strategyModuleRendered, plan, optimizedPlan, planDiff, planRendered) into a metadata-shaped record, passes it to the snapshot builder, and stores the result at `metadata.promptAssembly.snapshot`.

### Metadata

Stored only when the snapshot builder exists:

```typescript
metadata.promptAssembly.snapshot  // PromptAssemblySnapshot
```

Builder input is the promptAssembly metadata collected at Phase 0.958.

### Coexistence

The snapshot is **additive** — it coexists with all existing fields:

- `strategySelection`
- `strategySelectionRendered`
- `strategy`
- `strategyRendered`
- `strategyModule`
- `strategyModuleRendered`
- `plan`
- `optimizedPlan`
- `planDiff`
- `planRendered`

Nothing is removed or modified.

### NOT Modified

- `PromptRenderer` — unchanged
- `PromptContext` — unchanged
- `PromptCompression` — unchanged
- `Planner` — unchanged
- `Runtime` — unchanged
- `AgentLoop` — unchanged
- Prompt output — unchanged (metadata only, no prompt injection)

---

## Consequences

### Positive

1. **Snapshot produced** — the unified snapshot is now generated by production code
2. **Single inspection point** — `metadata.promptAssembly.snapshot` consolidates diagnostics
3. **Additive** — all existing metadata fields preserved
4. **Backward compatible** — optional field, no breaking changes
5. **No prompt changes** — metadata only
6. **Pure, stateless, deterministic** — snapshot generation follows the same principles as the foundation

### Negative

None.

### Neutral

1. Snapshot is generated only when the builder is explicitly configured
2. Snapshot reflects only fields populated at Phase 0.958 (before Phase 0.96 strategy resolution)
3. `promptAssemblyStrategy` (from Phase 0.96) is not included in the snapshot
